# Original Retro Quest typefaces

These are unmodified TrueType files fetched from the same Google Fonts CSS family/weight request used by the original reference:

`https://fonts.googleapis.com/css2?family=Pixelify+Sans:wght@500;700&family=Atkinson+Hyperlegible:wght@400;700&family=VT323&display=swap`
